# HA Control

Веб-панель управления Home Assistant, доступная из бокового меню (ingress).
Отдельный аддон: **не имеет отношения к туннелю `ha_link`** и не может его сломать.

## Что умеет (v0.1.0)

- Список установленных аддонов: состояние, версия, доступные обновления.
- Кнопки **Запустить / Стоп / Рестарт** для любого аддона.
- Просмотр логов аддона (последние N строк).
- Система: версия HA, Supervisor, ОС, память, swap, диск, load average.
- Бэкапы: список последних и кнопка «Создать полный бэкап».

## Чего не умеет (сознательно)

- Нет `docker_api` — панель не имеет root-доступа к хосту.
- Нет отдельного порта наружу: вход только через ingress HA (нужна авторизация HA).
- Нет обновления HA/аддонов и удаления бэкапов — только в следующих версиях.

## Права

`hassio_api: true`, `hassio_role: manager` — минимум, необходимый для
управления аддонами и бэкапами. Роль `admin` не используется.

## Установка

1. Магазин аддонов → репозиторий `https://github.com/Healtrap/ha-link-addon`.
2. Установить **HA Control**, запустить.
3. Иконка «HA Control» появится в боковом меню.

## Безопасность

- Трафик идёт через ingress Supervisor, наружу порт не публикуется.
- Токен Supervisor читается из окружения контейнера, нигде не хранится.
- Панель не пишет в конфигурацию HA и не меняет `ha_link`.
