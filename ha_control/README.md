# HA Control

Панель удалённого управления Home Assistant из бокового меню (ingress).
Отдельный аддон: **не имеет отношения к туннелю `ha_link`** и не может его сломать.

## Режим полного доступа (v0.3.x)

Панель даёт удалённый доступ ко всему, что нужно для ведения HA:

**Файлы — все каталоги HA, чтение и запись**
| Каталог | Что внутри |
|---|---|
| `/config` | `configuration.yaml`, `automations.yaml`, `scripts.yaml`, `scenes.yaml`, `.storage`, `www`, `themes`, `custom_components` |
| `/share` | общие файлы |
| `/media` | медиатека |
| `/ssl` | сертификаты |
| `/backup` | архивы резервных копий (можно скачать/залить/удалить напрямую) |
| `/app_configs` | конфиги аддонов |
| `/local_apps` | исходники локальных аддонов (можно создавать свои) |

- просмотр, чтение и редактирование текстовых файлов;
- **загрузка файлов** (drag-free, любое количество, до 2 ГБ, потоково);
- **скачивание** любого файла;
- создание файлов и папок, переименование, удаление;
- при перезаписи автоматически создаётся `<файл>.bak`;
- выход за пределы этих каталогов запрещён (никакого traversal).

Так можно менять автоматизации, скрипты, дашборды, карточки, темы, `configuration.yaml`
и `custom_components` — без Samba и без SSH.

**Аддоны**
- список, состояние, версии, обновления;
- запуск / остановка / рестарт / обновление / установка / удаление;
- логи любого аддона.

**Магазин**
- список репозиториев, добавление, удаление, перезагрузка магазина.

**Бэкапы**
- список, создание полного, скачивание через ingress, удаление.

**Система**
- HA / Supervisor / HAOS, память, swap, диск, load average, температура CPU;
- рестарт / стоп / старт HA Core, обновление HA;
- перезагрузка и выключение хоста (двойное подтверждение).

**Логи**
- HA Core, Supervisor, любой аддон; автообновление раз в 5 секунд.

## Права

| Ключ | Значение | Зачем |
|---|---|---|
| `hassio_api` | `true` | Supervisor API |
| `hassio_role` | `admin` | аддоны, магазин, ребут хоста |
| `docker_api` | **`false`** | доступа к Docker-сокету нет |
| `map` | 7 каталогов, `rw` | файловый менеджер |

Флаг «показывать в меню» и watchdog живут в `apps.json` Supervisor (по умолчанию off),
поэтому аддон включает их себе сам при каждом старте (`/addons/self/options`).

Если панели нет в меню: `Ctrl+Shift+R`, либо **Профиль → Редактировать боковую панель**.

## Безопасность

- Только ingress: наружу порт не публикуется, вход — по учётке HA и её 2FA.
- Панель видна только администраторам (`panel_admin: true`).
- Токен Supervisor читается из окружения контейнера, нигде не хранится.
- `docker_api` выключен: панель не может управлять контейнерами хоста напрямую.
- `ha_link` не затрагивается: другой контейнер, образ и workflow.

## Обновление

1. Правки в `ha_control/`, поднять `version:` в `ha_control/config.yaml`
   (CI упадёт, если `VERSION` в `control_server.py` не совпадает).
2. Actions → **build-control** → Run workflow.
3. HA → **Настройки → Аддоны → HA Control → Обновить**.
