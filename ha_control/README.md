# HA Control

Панель удалённого управления Home Assistant из бокового меню (ingress).
Отдельный аддон: **не имеет отношения к туннелю `ha_link`** и не может его сломать.

## Возможности (v0.2.0)

**Аддоны**
- список, состояние, версии, доступные обновления;
- запуск / остановка / рестарт;
- обновление, установка из магазина, удаление (с подтверждением);
- логи любого аддона.

**Магазин**
- список репозиториев, добавление и удаление;
- перезагрузка магазина (`store reload`).

**Логи**
- HA Core, Supervisor, любой аддон;
- автообновление раз в 5 секунд.

**Бэкапы**
- список последних, создание полного;
- скачивание архива через ingress (без Samba);
- удаление.

**Файлы** (`/config`, `/share`, `/ssl`)
- просмотр каталогов, чтение и редактирование текстовых файлов;
- при сохранении создаётся резервная копия `<файл>.bak`;
- путь жёстко ограничен этими тремя каталогами (выход за них невозможен).

**Система**
- версии HA / Supervisor / HAOS, память, swap, диск, load average, температура CPU;
- рестарт / стоп / старт HA Core, обновление HA;
- перезагрузка и выключение хоста (двойное подтверждение).

## Права

| Ключ | Значение | Зачем |
|---|---|---|
| `hassio_api` | `true` | доступ к Supervisor API |
| `hassio_role` | `admin` | установка/обновление аддонов, магазин, ребут хоста |
| `docker_api` | **`false`** | панель не имеет доступа к Docker-сокету |
| `map` | `config:rw`, `share:rw`, `ssl:ro` | файловый менеджер |

`docker_api` и произвольная консоль сознательно **не включены**: это фактически root
на хосте. Если понадобится — отдельная версия с явным предупреждением.

## Панель в меню

Флаг «показывать в меню» (`ingress_panel`) хранится в `apps.json` Supervisor, по умолчанию
выключен. Аддон при каждом старте проверяет его и **включает сам** (`/addons/self/options`),
поэтому после переустановки панель возвращается в меню автоматически.

Если панели нет: обнови страницу HA с очисткой кэша (`Ctrl+Shift+R`) или
**Профиль → Права → Редактировать боковую панель** и включи «HA Control».

## Безопасность

- Трафик идёт через ingress Supervisor, наружу порт не публикуется.
- Вход — по учётке HA (и её 2FA), панель видна только администраторам.
- Токен Supervisor читается из окружения контейнера, нигде не хранится.
- `ha_link` не затрагивается: другой контейнер, другой образ, другой workflow.
